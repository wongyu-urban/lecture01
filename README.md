# 진주시 아파트 전월세 가격 분석

2021년부터 2026년까지의 진주시 아파트 전월세 실거래 자료를 바탕으로 전세환산 보증금의 분포와 지역별 변화를 살펴본 분석 프로젝트입니다.

## 보고서

[진주시 아파트 전세환산 보증금 분석 보고서 보기](https://jinju-apt-report.pages.dev/)

## 분석 내용

- 전세환산 보증금의 분포와 평균·중앙값
- 제곱미터당 전세환산 보증금 분포
- 임대면적 분포와 약 60㎡·85㎡ 면적대의 거래 집중
- 읍·면·동별 연도 가격 변화
- 지도에서 지역을 선택해 거래 지표를 확인하고 지역 간 추이를 비교

월세 거래는 보증금과 월세를 하나의 기준으로 비교할 수 있도록 전세환산 보증금으로 변환했습니다. 보고서의 그래프와 지도는 마우스를 올리거나 지역을 선택해 상세 값을 확인할 수 있습니다.
